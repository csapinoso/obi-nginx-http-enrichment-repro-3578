# Cluster capture fixtures (PRO-11748 / #3578)

Sanitized artifacts from **gcp-dev-use1** / **pluto-us-test-www**. Regenerate with:

```bash
./scripts/capture-from-dev.sh
```

Requires a **short GitOps window**: stock OBI **v0.11.0** + `log_level: debug` on dev (see `scripts/capture-from-dev.sh` header). Revert to the custom agent pin after capture.

## What we learned from dev (2026-10-02)

| Observation | Detail |
|-------------|--------|
| **Wire shape** | `GET /` via openresty → app-shell: **`Content-Length: ~402 KiB`**, HTML, many `Set-Cookie` / `Vary` headers |
| **Proxy config** | Terranova uses `proxy-buffers-conf` (16k × 16) — mirrored in `nginx/proxy-buffers.conf` |
| **DEBUG fallback** | `reqErr=<nil>`, response-side `respErr` e.g. `malformed MIME header: missing colon: "00550"` (same family as #3578 `"0"`) |
| **Grep pitfall** | Co-located `otel-obi` on the www-web **node** often shows **0** fallback lines; **ingress** traffic → grep **cluster-wide** OBI logs |
